# 승인된 ZIP 동작

사용자 자원 전체, 미저장 현재 카드, 저장 템플릿 전체, 불러온 개인 글꼴 전체를 내보낸다. 같은 브라우저 프로필·origin의 자료가 대상이다.

- 버튼: `전체 자료 ZIP 다운로드`. 개인 글꼴 입력: `개인 글꼴 파일`. 적용 선택기: `개인 글꼴 선택`.
- 현재 카드는 최신 JSON과 현재 비율/선택한 해상도의 전체 PNG로 보존한다. 템플릿은 선택 여부와 무관하게 각각의 JSON과 참조 원본을 보존한다.
- 개인 글꼴은 TTF/OTF, 파일당 10,000,000바이트까지다. 실제 로드/검증 뒤 보관하고 적용한다. 미사용 글꼴도 보관·내보낸다. 새로고침 후 개인 글꼴을 쓰는 템플릿을 불러올 수 있어야 한다.
- 기본 이미지는 참조된 것만 포함하고 기본 글꼴은 이름으로 참조한다.
- 원본은 SHA-256 기준으로 한 번만 담고 바이트를 유지한다. 자원 이름·분류와 JSON 참조를 연결한다.
- 내부 경로는 안전한 식별자로 만들고 표시 이름은 별도 보존한다. 같은 이름의 항목도 보존한다.
- 경로: `jjal-export/manifest.json`, `resources/index.json`, `creations/current/document.json`, `creations/current/preview.png`, `creations/templates/template-0001.json` 등, `assets/images/<sha>.<ext>`, `fonts/<sha>.<ext>`.
- 비압축 엔트리 전체(JSON/PNG/이미지/글꼴/manifest)는 합계 100,000,000바이트까지다. ZIP 헤더 제외. 초과/누락/해시 손상은 전체 실패이며 일부만 성공 처리하지 않는다.
- 시작 시점 스냅샷과 중복 실행 차단. 성공 메시지는 `ZIP 다운로드를 시작했습니다`. 기존 카드·저장 자료를 변경하지 않는다.
- ZIP 전체 가져오기 UI는 후속이다. 아카이브 JSON이 기존 Base64 JSON과 호환된다고 안내하지 않는다. 기존 기본 글꼴 JSON 흐름은 유지한다.
