# 과제5 준비 기록

2026-10-27 사용자 승인으로 공개 소스 스냅샷을 독립된 로컬 저장소에 가져왔다. 과제3 private Git 이력과 기획 원문은 복제하지 않았다.

합성 PNG·TTF·OTF와 문서·101개 템플릿을 준비했다. 실제 Chrome에서 문서 스키마와 두 FontFace 로드를 검증했다. 최초 준비 실행은 새 버튼이 없는 상태에서 다운로드 대기 Promise 예외를 처리하지 못해 중단됐다. 동결 전 검사 도구의 예외 처리와 픽셀 해시 비교를 보완했다. 다음 준비 실행에서 10개 전부 실행되어 0 PASS/10 FAIL을 기록했다. 이 준비 실행은 AI A의 작업 회차나 사용 시간에 합산하지 않는다.

사용자의 이번 요청은 준비→동결→구현의 순차 실행을 승인했다. A 작업 시계는 동결이 끝나고 공통 최초 요청을 실제 구현 지시로 활성화하는 시점부터 시작한다. 이 시점과 시작 소스 커밋을 별도 기록한다. 현재 대화의 작업 지시 1건을 A의 최초 요청으로 집계하고 후속 지시가 있으면 추가한다.

A 역할은 ZIP 코어·원본 무결성·용량 검증을 구현하는 것이다. UI와 개인 글꼴 적용/템플릿 연결은 B의 이어받을 작업이다. B의 새 대화/다른 모델 조건은 아직 실행되지 않았다.
