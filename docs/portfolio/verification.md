## 입력 보존과 회귀 전략

단위 검사는 문서 스키마·참조, 편집 좌표, 변형, 잠금·숨김, 잘못된 값의 상태 보존을 확인합니다. 브라우저 검사는 실제 클릭·드래그와 모바일 터치 입력, 저장·새로고침·복원, 실제 다운로드 파일을 확인합니다.

이전 단계에서는 PNG/JPEG 입력, 극단 입력 12건, 템플릿 3개 이상의 CRUD·영속성, 정상 JSON 복원과 손상·누락 JSON 거부를 검증했습니다. 이 로컬 기능 근거와 최신 변경 검사의 범위를 함께 보존하며, 과거 전체 검사를 최신 배포에서 다시 실행했다고 표현하지 않습니다. 제출 기준별 구분은 [현재 상태표](acceptance-matrix.md)에 있습니다.

## 아직 확인하지 않은 것

- 실물 Android·iOS 기기, Safari와 다른 OS의 호환성
- 10명 동시 사용 및 열기·저장·출력의 운영 성능 목표
- 서버 계정, 실제 편집권 전환, 공동 작업, 클라우드·자동 저장과 백업 복구
- 외부 AI의 실제 호출·품질·시간·원가, 개인 키 관리와 과금
- 1 CSS px까지 축소한 도형의 브라우저 끝점, 최신 도형 조절의 별도 키보드·실행 취소 시나리오
- 접근성 전체 적합 판정, 정식 제출 묶음 전체의 합격 판정

브라우저 에뮬레이션은 실물 기기 검사를 대신하지 않습니다. Canvas와 PNG가 일치하더라도 디자인의 완성도나 실제 사용성까지 수치 하나로 판정하지 않습니다. 기존 번들 크기 경고도 남아 있습니다.
