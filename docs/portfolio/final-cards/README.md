2026-10-24에 새로 구성한 문구와 기본 도형으로 제작하고 **사용자가 최종 제출 자료로 승인한 카드3장**입니다. 기존 검사 PNG를 복사하거나 이름만 바꾸지 않았습니다. 카드 파일의 바이트·문구·비율은 검수한 제작B와 동일합니다.

실제 [공개 앱](https://jjal-card-studio-three.vercel.app/)의 JSON 가져오기 → 새로고침 → 템플릿 불러오기 → PNG 저장으로 내려받았습니다. 자체 작성한 조판 JSON을 앱의 정상 가져오기 검증에 통과시켰으며, 렌더러를 직접 호출해 별도 PNG를 만든 방식이 아닙니다.

## 제작·이용 권리 근거

문구와 해·초승달·산·충전 표시의 구도는 이번 제출 자료를 위해 AI 보조로 새로 구성했습니다. 앱의 원·사각형·삼각형·마름모를 조합했으며, 외부 사진·캐릭터·로고·이모티콘·사용자 원본 이미지를 사용하지 않았습니다. 문서에 포함한 이미지 소재는 0개입니다. 사용자의 직접 수작업이라고 대신 주장하지 않습니다.

세 카드의 글꼴은 앱에 포함된 **Noto Sans KR**입니다. [글꼴 출처·이용 조건](https://github.com/jkimsvsd-code/jjal-card-studio-portfolio/blob/main/THIRD-PARTY-NOTICES.md)과 [동봉 OFL 1.1 전문](https://github.com/jkimsvsd-code/jjal-card-studio-portfolio/blob/main/apps/demo/public/assets/fonts/notosanskr/OFL.txt)에 근거합니다. 해당 라이선스는 글꼴로 만든 이미지 결과물의 이용을 허용하며 결과 PNG에 글꼴 라이선스를 적용하도록 요구하지 않습니다. 글꼴 원본은 수정하지 않았습니다.

사용자는 AI 보조 제작 사실과 자신의 기획·선택 역할을 확인하고 세 카드를 최종 제출 자료로 승인했습니다. 이번 확정은 제출처 전송이나 사용자의 직접 수작업 제작을 뜻하지 않습니다.

## 공개 이미지 검사

세 파일의 PNG 시그니처, 실제 치수, 모든 청크 CRC와 이미지 압축 스트림을 확인했습니다. 청크는 **IHDR·IDAT·IEND**뿐이며 끝에 추가 데이터가 없습니다. 위치 정보를 담는 EXIF와 텍스트 메타데이터 청크는 각각 0개입니다.

직접 연 이미지에는 위 창작 문구와 도형만 있습니다. 실명·연락처·개인 주소·좌표·계정 식별자·인증 값은 포함하지 않았습니다. 이 확인은 위 고정 SHA-256의 파일에 한정하며 최종 제출 묶음 전체의 개인정보·비밀값 검수와는 구분합니다.

## 첫 후보와 보완

첫 제작 A에서는 다운로드·재개방·픽셀 일치가 통과했지만, 조판 JSON에 전체 기본 배경을 빠뜨려 02의 흰 문구가 밝은 배경에서 잘 보이지 않았습니다. 직접 시각 확인에서 발견해 후보로 채택하지 않았습니다. 전체 배경을 명시한 입력 B로 세 카드를 앱에서 다시 내려받고 같은 파일 검사를 수행했습니다.

확정·공개하는 파일은 위 B의 최종 세 카드입니다. A와 B의 원본 입력·실행 결과·화면·다운로드는 비공개 기록에 보존했습니다. 이는 후보 제작 입력의 보완이며 제품 코드를 수정한 결함 사례로 계산하지 않습니다.
