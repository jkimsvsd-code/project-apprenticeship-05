## 확인 방법 4줄

위치: https://jjal-card-studio-three.vercel.app/ 의 문구·도형·템플릿·저장 도구입니다.
행동: 문구·도형·자원을 추가 → 템플릿 저장·새로고침·불러오기 → PNG 다운로드 순서로 확인합니다.
통과 모습: 편집 내용이 복원되고 다운로드 PNG의 치수·내용이 미리보기와 일치합니다.
실패 모습: 선택한 도형의 외곽 HEX에 #ZZZZZZ를 입력하면 오류가 표시되고, 기존 색·작품 JSON 전체·미리보기가 유지됩니다.

PC와 Pixel 7 브라우저 에뮬레이션에서 실제 공개 UI로 확인했습니다. 실패 보존은 1:1 새 도형의 외곽 HEX에 한정합니다.
