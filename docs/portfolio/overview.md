# 짤 카드 스튜디오

자신의 이미지와 문구를 조합해 짤과 짧은 캐릭터 콘텐츠를 만드는 웹 편집기입니다. 같은 소재를 여러 장면과 화면 비율에서 다시 사용할 수 있도록, 이미지 파일뿐 아니라 편집 가능한 템플릿도 저장합니다.

[앱 실행](https://jjal-card-studio-three.vercel.app/) · [공개 저장소](https://github.com/jkimsvsd-code/jjal-card-studio-portfolio) · 제작·관리: **jkimsvsd-code**

## 해결하려는 문제

친구에게 보낼 짤 하나를 만들 때도 이미지 가져오기, 문구 배치, 말풍선 조정, 화면 비율 변경을 반복하게 됩니다. 편집 도구를 찾다가 작업 화면을 놓치거나, 저장한 이미지가 미리보기와 다르거나, 잘못된 파일을 골라 기존 작업이 사라지면 흐름이 끊깁니다.

이 프로젝트는 카드 위에서 직접 요소를 조작하고, 자원을 폴더에 모아 다시 쓰며, 저장·출력 전에 입력과 렌더링을 검증하는 흐름에 집중했습니다. 사용자가 승인한 요구를 작은 구현 단계로 나누고, 결정 이유와 실제 실패·수정·재검 결과를 함께 기록했습니다.

## 현재 구현 범위

| 영역        | 동작                                                                        |
| ----------- | --------------------------------------------------------------------------- |
| 카드        | 1·2·4컷, 초기 템플릿 6종, 8개 화면 비율                                     |
| 자원        | 이미지 불러오기, 브라우저 캐시와 폴더 분류, 반복 추가와 카드 배치           |
| 문구        | 여러 문구, 화면에서 내용 편집, 글꼴·색·외곽선·정렬, 크기 조절               |
| 말풍선·도형 | 말풍선 4종, 정사각형·원·정삼각형·마름모, 추가 후 독립적인 가로·세로 조절    |
| 레이어      | 선택·이동·회전·반전·순서 변경, 잠금·숨김·그룹·복제·컷 간 복사               |
| 배경        | 작품 전체·컷별 이미지, 위치·확대, 투명 배경, 원본과 결과 이미지 전환        |
| 저장        | 브라우저 템플릿 CRUD, 새로고침 후 저장 내용 유지, 이미지가 포함된 JSON 교환 |
| 출력        | PNG·JPEG·WebP, 작품 전체·개별 컷, 출력 크기와 투명도 선택                   |
| 이력        | 현재 편집 세션의 실행 취소·다시 실행                                        |

지원 화면 비율은 **1:1, 4:5, 3:4, 2:3, 9:16, 4:3, 3:2, 16:9**입니다. 내용과 서식은 공유하면서 배치는 비율마다 보존합니다. PC는 클릭·드래그, 모바일은 터치와 길게 누르기·드래그를 사용합니다.

## 기획과 구현의 경계

현재 공개 앱은 로그인 없이 사용하는 브라우저 편집기입니다. 계정 기반 저장, 서버의 편집권 관리, 공동 작업, 외부 AI 배경 제거·표정 변경, 결제는 후속 범위입니다. 결과 이미지 파일을 불러오는 기능을 실제 AI API 연동으로 표현하지 않습니다.

최대 50명·2주 시험 운영은 기획이며 아직 실시 결과가 없습니다. 실물 휴대전화, Safari·다른 OS, 동시 사용 성능과 운영 복구도 별도 검증 대상입니다. [검증 범위](verification.md)와 [제출 준비 상태](submission.md)를 구분해 공개합니다.
