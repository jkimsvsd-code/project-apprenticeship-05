# 작품·템플릿과 브라우저 저장

## 공통 작품 모델

실제 스키마는 `packages/document-model/src/index.ts`에 있다. 작품은 `kind: jjal-document`, `schemaVersion: 1`과 ID·제목·시각·활성 비율·자원·컷·요소·레이아웃으로 구성된다. 문구·이미지·캐릭터·말풍선·도형·컷 배경·테두리를 요소로 표현한다.

요소 내용과 레이어 순서는 공유하고, 위치·크기·회전·반전은 8개 비율별 레이아웃에 저장한다. 컷 사각형은 캔버스 기준 0~1, 요소 배치는 컷 기준 정규화 좌표다. 논리적 긴 변 1080px을 기준으로 계산한 같은 배치를 미리보기와 출력에 사용한다.

전체 바탕은 비레이어 배경이다. 컷별 배경과 컷 테두리는 레이어이며 처음에는 같은 그룹으로 만든다. 그룹 ID는 선택·변형의 묶음을 표현하고 이미지 자원 자체와 구분한다. 새 ID로 복제할 때 요소·그룹·이미지 참조도 다시 연결한다.

새 정사각형·원·마름모의 기본 폭과 높이는 같고, 정삼각형은 실제 외곽선 안쪽의 세 변을 맞춘다. 이후에는 폭·높이를 자유롭게 편집하며 과거 저장 배치를 새 기본값으로 덮어쓰지 않는다.

## 템플릿과 JSON

템플릿은 독립 ID·이름·시각과 작품을 가진다. JSON 백업은 `kind: jjal-template-backup`, `schemaVersion: 1`, 내보낸 시각, 템플릿과 Base64 이미지 본문으로 구성된다. 구현은 `packages/template-kit`에 있다.

가져오기는 구조·필드·버전·크기·참조·중복과 실제 이미지 바이트를 검증한다. 이미지는 SHA-256·MIME·디코딩 치수로 확인하며, 통과한 자료는 새 ID의 사본으로 저장한다. 잘못된 JSON 때문에 기존 템플릿·현재 편집 내용이 일부 바뀌지 않도록 검증과 저장 경계를 둔다.

현재 JSON은 파일당 최대 25MB·템플릿 100개·고유 이미지 합계 4천만 픽셀의 보호 한도를 둔다. 현재 컷의 콘텐츠 한도는 100개이며 컷 배경·테두리 예약 레이어는 별도다. 구체적 경계는 스키마와 검사 코드를 따른다.

비밀 키·계정 권한·외부 파일 경로·브라우저 세션의 실행 취소 이력은 JSON에 저장하지 않는다. 새 선택 필드를 모르는 과거 strict 클라이언트는 자료를 거부할 수 있으므로 버전 숫자만으로 이전 앱 호환성을 보장하지 않는다.

## 로컬 보관과 세션 경계

`packages/persistence`의 IndexedDB 저장소는 템플릿·이미지 Blob·내 스타일·자원 캐시를 보관한다. 같은 원본 이미지는 해시로 재사용하고 카드에 배치할 때마다 독립 요소 ID를 만든다. 사용자 폴더의 분류 정보는 브라우저 로컬 메타데이터로 관리한다.

저장 위치는 접속한 브라우저와 origin에 종속된다. 로컬 주소와 공개 앱, 다른 브라우저 사이에서는 JSON 백업으로 옮긴다. 현재 편집 세션의 실행 취소·다시 실행은 메모리 전용이며, 템플릿을 저장한 것과 자동 저장·클라우드 동기화는 구분한다.

PNG/JPG/WebP 형식·출력 해상도·전체/개별 컷·출력용 투명 옵션은 세션 UI 상태다. 문서 배경의 투명 설정과 출력 시에만 적용하는 배경 제외 옵션은 서로 다르다. JPG는 투명 픽셀을 지원하지 않는다.

계정·서버 저장·공동 편집 권한·AI 작업·결제는 현재 구현하지 않았다. 공개 사본은 브라우저 편집기의 재현 가능한 코드만 제공한다.
