# 편집 작업공간

## 카드 중심 구성

PC와 가로 화면은 카드와 직접 편집 도구를 나란히 두고, 자원 영역도 같은 화면 안에서 접근한다. 긴 내용은 도구 내부에서 스크롤한다. 모바일은 도구 제목을 눌러 본문을 펼치고 닫으며 카드를 확인할 공간을 유지한다. 모든 도구가 한 번에 보이는 구성은 아니다.

배경은 짙은 네이비, 선택 면은 크림색, 직접 조작 표시는 하늘색, 저장 동작은 따뜻한 색으로 구분한다. 카드의 실제 배경·소재·글자색은 UI 표면 색과 독립적이며 출력에는 UI 그림자·선택 윤곽이 포함되지 않는다. 불필요한 소개·홍보·사용법 문장은 화면에서 줄이고 조작 이름·필수 상태·오류·접근성 이름은 유지한다.

## 추가와 선택

문구 섹션의 `문구 추가`는 기존 문구를 교체하지 않고 새 레이어를 만든다. 자원은 브라우저에 캐시하며 같은 이미지도 여러 번 독립 배치할 수 있다. 미분류·기본·말풍선과 사용자 폴더를 사용하고, 폴더별 추가 버튼의 이름은 선택한 폴더를 따른다.

카드의 빈 곳을 누르면 선택을 해제하고 요소 위를 누르면 해당 위치의 가장 위 레이어를 선택한다. 레이어 목록에서도 선택할 수 있다. 그룹은 살짝 겹친 레이어 표시로 구분하고 전체 레이어 개수를 표시한다. PC 우클릭 또는 모바일 길게 누르기 메뉴에서 상세 보기·관련 작업에 접근한다.

잠금은 선택 확인과 별개로 이동·변형·삭제를 보호한다. 숨긴 레이어는 출력하지 않는다. 다중 선택의 `선택 해제`는 선택 항목과 다중 선택 모드를 함께 해제한다. 문구·도형 도구로 전환할 때는 해당 도구가 편집할 수 있는 대상으로 선택을 정리한다.

## 직접 조작

PC는 클릭·드래그, 모바일은 길게 누른 뒤 드래그로 조절한다. 모서리 손잡이는 크기, 회전 손잡이는 각도를 조절한다. 문구는 더블클릭·길게 누르기로 카드 위에서 내용을 수정하며 조합 입력 중에는 탐색·변형과 충돌하지 않도록 보호한다.

도형 선택기는 글자 설명 대신 실제 모양을 표시하고 접근성 이름을 제공한다. 처음 추가하는 네 도형은 정사각형·원·정삼각형·마름모다. 이후 변 중앙 손잡이는 반대 변을 고정하고 가로 또는 세로만 바꾸며, 모서리에서는 두 축을 함께 바꿀 수 있다. 작은 요소에서도 조작 손잡이는 터치할 공간을 따로 확보한다.

말풍선은 폭·높이, 중앙 문구와 사방 여백, 꼬리 방향·길이, 네 모서리 둥글기와 외침 가시의 예리함을 조절한다. 생각 말풍선의 자원 미리보기와 카드 윤곽은 같은 기하를 사용한다. PNG 말풍선 변환은 입력 그림의 윤곽을 바탕으로 편집 가능한 자원을 만드는 로컬 기능이며 AI 배경 제거와 구분한다.

## 저장과 경계

`저장`의 이미지 도구에서 PNG/JPG/WebP 파일을 만들고, 템플릿·JSON 도구에서 편집 가능한 자료를 보관한다. 배경색을 끄는 설정은 문서 내용이고 출력용 투명 옵션은 해당 출력에만 적용한다.

현재 읽기 전용 모드는 표시·비활성 UI 검토를 위한 것이다. 다른 기기의 실제 계정 편집권, 서버 권한과 공동 작업은 구현하지 않았다. 모바일 터치는 브라우저 에뮬레이션으로 검증했으며 실물 기기 전체 검수를 대신하지 않는다.
