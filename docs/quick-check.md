# 확인 방법

1. 위치: 과제5 편집기의 저장 → 전체 자료 ZIP 다운로드. B 종료 시점에 UI가 연결되어 고정 검사 10/10을 통과했다. 개인 글꼴은 같은 화면의 `개인 글꼴 파일`·`개인 글꼴 선택`에서 불러와 적용한다.
2. 행동: 카드 편집/템플릿 저장 → ZIP 버튼 → ZIP 내용 확인의 3단계.
3. 통과: 현재 카드 JSON/PNG, 저장 템플릿 전체, 사용자 자원 전체, 개인 글꼴 전체가 ZIP 하나에 있고 원본 해시가 일치한다.
4. 실패: 누락·손상·용량 초과의 원인을 표시하고 다운로드하지 않으며 기존 카드·저장 자료를 유지한다.
