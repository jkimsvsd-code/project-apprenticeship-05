# 검사 실행과 범위

Node 24 / npm 11로 저장소 루트에서 실행한다.

```sh
npm ci --ignore-scripts
npm run check
```

`check`는 타입 검사 → ESLint → Vitest → Vite 빌드 순서다. 단위 검사는 작품 스키마·입력 보존·템플릿/JSON·이미지·렌더링·편집 명령·도형 기본값·독립 축 조절·레이어/그룹·세션 이력을 다룬다. 글꼴·기본 소재의 실제 파일과 해시·권리 고지도 읽으므로 해당 파일을 제거하지 않는다.

## 브라우저 검사

기본 설정은 Playwright Chromium의 PC·Pixel 7 에뮬레이션이다. 처음 실행할 때 검사 브라우저를 명시적으로 설치한다.

```sh
npm exec -- playwright install chromium
npm run test:e2e
```

기본 검사는 `127.0.0.1:4173`에서 자체 서버를 시작·종료한다. 같은 포트를 사용하는 기존 서버가 있으면 먼저 별도 작업과 충돌하지 않는지 확인한다. 설치된 Edge를 쓰려면 PowerShell에서 `$env:PLAYWRIGHT_CHANNEL = 'msedge'`로 지정할 수 있다. 해당 실행은 Edge 검사로 기록한다.

기능별 `playwright.*.config.ts`는 특정 검수 당시 사용한 선택 실행 설정이다. 일부는 `msedge`와 `127.0.0.1:4190`의 개발 서버 재사용을 명시하므로 실행 전에 설정을 확인한다. 다른 브라우저의 설치만으로 이 설정이 자동 전환되지는 않는다.

`tests/fixtures/images`는 직접 그린 합성 입력과 의도적인 오류 파일이다. 실제 이용자 업로드를 포함하지 않는다. 검사 결과·trace·다운로드 파일은 로컬 출력이며 Git 추적 대상이 아니다.

## 확인한 결과

2026-10-24 S01-27 원본 고정 소스에서 타입·lint·빌드와 **44파일 673개 단위 검사**가 통과했다. 브라우저는 첫 실행 **8 PASS / 1 FAIL**, 새로고침 후 화면 준비 대기를 보완한 해당 1개 재검 PASS로 **유일 9개 사례**의 최종 통과를 확인했다. 실패를 최초 실행에서 없었던 것으로 바꾸거나 재검을 추가 성공 사례로 합산하지 않는다.

새 기본값은 4종 × 1·2·4컷 × 8비율의 실제 기하를 단위로 확인했다. 브라우저는 PC·모바일 각각 네 도형을 추가하고 저장 JSON의 비율별 크기를 확인했으며, 8비율에서 도형을 교대해 가로·세로 손잡이를 조절했다. 회전·반전·다른 축·반대 변 고정과 기존 요소 보존을 확인하는 단위·브라우저 범위를 구분한다.

실제 PNG **35개**를 편집 Canvas와 비교한 전체 RGBA **115,361,280채널 차이는 0**이었다. 이는 작은 선택기와 큰 카드의 서로 다른 해상도까지 픽셀이 같다는 뜻이 아니다. 템플릿 저장·새로고침 뒤 복원·JSON 대조도 포함한다.

같은 날 공개 URL 검사는 PC·Pixel 7 각 9단계, 총 **18단계**와 PNG **4개**를 별도로 확인했다. 원본 과거 결과·공개 URL 검사·새 Public 사본의 재현 검사는 각각의 실행으로 구분한다.

## 검증 한계

현재 증거는 Windows 브라우저와 터치 에뮬레이션 범위다. 실제 iOS/Android·Safari·다른 OS·동시 사용 성능·서버 권한·접근성 전체 적합·제품 전체 인수 완료를 의미하지 않는다. 새 도형의 1 CSS px 크기 하한도 끝점 실측을 완료한 것으로 표현하지 않는다.

추가 검사는 원본에서 구현·검증한 뒤 공개 내보내기로 반영한다. Public 정본을 직접 수정하지 않는다.
