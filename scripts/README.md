# 수동 개발 도구

| 도구                         | 역할                                                  | 실행 경계                               |
| ---------------------------- | ----------------------------------------------------- | --------------------------------------- |
| `generate-starter-assets.py` | 프로젝트의 기하 도형 기반 기본 PNG 소재 생성          | Python·Pillow가 필요한 명시적 개발 작업 |
| `fetch-fonts.py`             | 고정한 공식 커밋의 기본 글꼴·라이선스·메타데이터 복구 | 명시적으로 실행할 때만 공식 출처에 접속 |
| `prepare-vercel-release.mjs` | 검사한 정적 빌드를 로컬 업로드 패키지로 복사          | 원격 호출·업로드·기존 출력 삭제 없음    |

앱 실행·일반 빌드·이미지 다운로드가 이 Python 도구를 자동 실행하거나 외부 글꼴 서버에 접속하지 않는다. 제공 파일을 그대로 사용하는 데 Python·Pillow는 필요하지 않다. 합성 검사 이미지의 생성 코드는 `tests/fixtures/generate-images.py`에 있다.

`npm run release:prepare`는 기존 `apps/demo/dist`가 필요하며 `.vercel/output`이 이미 있으면 중단한다. source map·심볼릭 링크·경계 밖 경로를 거부하고 필수 권리 고지를 함께 복사한다. 자세한 경계는 [빌드 문서](../docs/deployment.md)를 따른다.

공개 사본 생성 정책과 발행 절차는 Private 원본에서 관리한다. 이 디렉터리를 수정해 Public에 직접 반영하거나 Public에서 원본으로 동기화하지 않는다.
